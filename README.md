# Методы генерации медицинских описаний коронарных ангиограмм на основе визуально-языковых моделей с использованием внешних медицинских знаний

**Студент:** Шабаев Константин Владиславович

**Научный руководитель:** Ковальчук Сергей Валерьевич, доцент факультета технологий искусственного интеллекта

**Организация:** Университет ИТМО

**Отчёты:** [Эксперимент 1: zero-shot VLM на ARCADE с RAG и без](REPORT.md)

## Тема

Система получает коронарную ангиограмму и формирует структурированное медицинское описание: какие артерии и сегменты видны, есть ли признаки стенозов, где они расположены и насколько модель уверена. Основа системы — открытые визуально-языковые модели (VLM). Их дополняет база знаний об анатомии коронарных артерий, сегментах SYNTAX, ангиографических проекциях и медицинской терминологии (RAG).

## Цель

Разработать метод генерации структурированных описаний коронарных ангиограмм на основе VLM с внешними медицинскими знаниями, который снижает долю фактических ошибок по сравнению с базовыми VLM. Проверка проводится на разметке датасета ARCADE.

## Направления исследования

1. **Структурированная генерация.** Модель сначала заполняет схему «артерия → сегмент → стеноз → степень → уверенность», а затем схема преобразуется в текст заключения. Так каждое утверждение можно проверить отдельно.
2. **Привязка к изображению.** Каждое утверждение связывается с областью снимка, и его корректность проверяется по маскам ARCADE. Если данных недостаточно, модель явно об этом сообщает.
3. **Способы организации RAG.** Сравниваются текстовый поиск (BM25), плотный поиск, поиск по анатомическим структурам и граф знаний.

## Задачи

1. Обзор VLM в медицине, методов RAG и работ по анализу ангиограмм (CAG-VLM, 2025; Jiang et al., 2026).
2. Построение эталонных структурированных описаний по разметке ARCADE.
3. Сбор базы знаний: сегменты SYNTAX, ветви, проекции, терминология.
4. Бейзлайн: 2–3 открытые VLM без RAG (Qwen2.5-VL, InternVL, MedGemma).
5. Структурированный вывод и привязка утверждений к областям изображения.
6. Сравнение вариантов RAG.
7. Метрики: F1 по сегментам и стенозам, доля галлюцинаций, качество отказов, калибровка уверенности; анализ ошибок.
